# Kotoba

Ứng dụng học tiếng Nhật dành cho người Việt.

## Chức năng dự kiến

- Học và luyện tập từ vựng, ngữ pháp, Hán tự từ N5 đến N1.
- Sổ từ vựng cá nhân: mỗi hàng gồm từ vựng, nghĩa và ví dụ.
- Lưu dữ liệu học tập bằng Supabase.

## Định hướng công nghệ

- Frontend: Next.js hoặc React.
- Database: Supabase.
- Mã nguồn: GitHub.
- Ưu tiên phương án triển khai miễn phí.

## Trạng thái

Dự án đang khởi tạo; repository hiện chưa có mã nguồn ứng dụng.
